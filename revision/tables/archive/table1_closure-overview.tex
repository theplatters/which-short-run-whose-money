%   \centering centres a line through the \leftskip/\rightskip fil, and
%   \newline bypasses it: it tears the line before the break out of the
%   centring and lands 2-14 pt off centre (measured). \par, \linebreak,
%   \shortstack[c] and a nested tabular all centre exactly; \par is the
%   least surprising of the four and is what is used below.
%   Measured on a controlled test (column centre = 0):
%     \newline  -> -2.5 pt on the line before the break
%     \par      ->  0.0 pt on both lines
%     \linebreak->  0.0 pt on both lines
%   The three columns are equal p{4.5cm} with \centering so that wrapped
%   text is centred too (a bare c-column does not wrap).
